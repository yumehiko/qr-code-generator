# 公開準備セキュリティ監査（2026-09-07）

## 対象と方法

この監査は公開準備時点の全到達可能 Git 履歴・参照、HEAD の追跡対象、`.claude`、`.spec-workflow`、配布用 DMG、画像アセット、署名・リリース用シェルスクリプトを対象にした。

次の確認を行った。検出値そのものは記録・出力していない。

- 到達可能なコミット、ブランチ、タグ、ファイル名を確認した。
- よくあるアクセストークン、秘密鍵ヘッダー、資格情報用の環境変数代入を、履歴とHEADでパターン検索した。
- 追跡済みローカル設定と承認記録は、値を読まずキー構造とファイル種別を確認した。
- 署名スクリプトはコード署名・公証・Keychain・ID・資格情報・ローカルパスの参照有無を確認した。
- DMG と画像はファイル形式、拡張属性、埋め込み文字列の機械的スキャンを行った。圧縮・バイナリ由来の文字列一致は内容の漏えいを意味しないため、これ単独で秘密情報とは判定しない。

## HEADで行った修正

- 追跡されていたローカルエージェント許可設定を削除した。
- 追跡されていたワークフロー承認記録を削除した。仕様文書は残している。
- 追跡されていた生成済みDMGを削除した。配布物はリリース工程で再生成する。
- `.gitignore` にローカルエージェント状態、承認記録、DMG、環境設定、署名・証明書形式を追加し、再混入を防止した。

アプリのQR生成・書き出し機能、ソース、アイコンアセット、アドホック署名スクリプトの動作は変更していない。

## 結果

- 監査した到達可能履歴とHEADで、対象パターンに一致するトークン、秘密鍵、資格情報の代入は検出されなかった。
- 署名スクリプトに固定の署名ID、Keychain参照、パスワード、トークン、公証設定、ローカル絶対パスは検出されなかった。現在はアドホック署名である。
- 追跡画像は標準的なPNG/ICNS形式だった。DMGと画像にmacOSの`com.apple.provenance`拡張属性が見えたが、Gitの追跡内容ではない。DMGは今回削除した。

## 限界と公開判断が必要な事項

- 到達不能オブジェクト、他のclone、GitHubのキャッシュ・fork、外部配布物、ローカルの拡張属性は、このPRで消去できない。過去に機密情報を含めた疑いがある場合は、管理者が失効と履歴改変の要否を判断する必要がある。
- GitHubの公開設定は変更していない。公開に切り替える前に、管理者がリポジトリ設定、Actions secrets、Deploy keys、環境変数、リリース添付物、fork とアクセスログを別途確認する必要がある。
- 本監査はパターン検出であり、未知の形式の秘密情報や第三者サービス側の保持データを保証するものではない。
